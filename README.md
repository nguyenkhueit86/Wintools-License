Bộ công cụ Windows đa chức năng: thông tin hệ thống, mạng, USB, sửa lỗi Windows/Máy in, driver, gỡ ứng dụng, cài đặt Windows & Office, bản quyền và nhiều tiện ích khác.

---

## Chức năng chính

| Nhóm | Mô tả ngắn |
|------|-------------|
| **Tổng quan** | Gauge CPU, RAM, GPU, ổ đĩa, mạng theo thời gian thực; thông tin phần cứng cơ bản. |
| **Thông tin hệ thống** | OS, CPU, RAM, bo mạch, đồ họa, ổ đĩa, adapter mạng, BIOS; xuất báo cáo. |
| **Công cụ file** | Tiện ích thao tác file và thư mục. |
| **Mạng / Internet** | Ping, xem Public IP, WHOIS; cấu hình mạng. |
| **Kết nối đang mở** | Danh sách kết nối TCP (PID, process, địa chỉ/port). |
| **Quản lý USB** | Liệt kê cổng/thiết bị USB, ghi chú, bật/tắt sử dụng. |
| **Sửa lỗi Windows** | SFC, DISM, DNS, Winsock, dọn temp, Windows Update, v.v. |
| **Sửa lỗi máy in** | Spooler, RPC, USB Monitor; mở Quản lý máy in. |
| **Bản quyền** | Kiểm tra bản quyền Windows & Office; nhập/kích hoạt mã bản quyền. |
| **Gỡ ứng dụng** | Gỡ cài đặt phần mềm. |
| **Dò driver** | Quét thiết bị, sao lưu/khôi phục driver, cập nhật qua Windows Update, tìm driver trên web. |
| **Công cụ khác** | Các tiện ích bổ sung. |
| **Tính năng mở rộng** | Backup & Restore profile trình duyệt (Chrome, Edge). |
| **Cài đặt Win & Office** | Cài đặt / gỡ / kích hoạt Microsoft Office và hỗ trợ cài đặt Windows. |
| **Cài đặt** | Giao diện (sáng/tối), ngôn ngữ (Vi/En), khởi động cùng Windows, chính sách (Regedit, Services, Task Manager), audit log, nhập mã bản quyền. |
